# Project Docs

Documentation for agents working on this codebase. Read in this order:

1. [status.md](status.md) — what works, what's stubbed, what's missing (read first)
2. [plan.md](plan.md) — prioritized roadmap and decisions
3. [reference.md](reference.md) — project structure, endpoints, and conventions
4. [changelog.md](changelog.md) — append-only log of changes

Agent rules:

- After finishing a task: update `status.md`, add a line to `changelog.md`, and check off the item in `plan.md`.
- After structural changes (new route, new model, new file): update `reference.md`.
- Keep these files accurate — stale docs are worse than no docs.
